# Jogo Space Invaders

Uma versão simples e interativa do clássico jogo Space Invaders, em que o jogador controla uma nave e deve destruir os inimigos que se aproximam.

## Funcionalidades

- Controle da nave
- Disparos contra os inimigos
- Movimentação dos inimigos
- Sistema de pontuação
- Controle da partida

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
